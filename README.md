# PIXELFORGE — Creative Photo Studio

Мобильный фоторедактор на чистом HTML/CSS/JavaScript. Работает в браузере телефона без регистрации и платных API.

## Открыть сайт

После включения GitHub Pages: https://yalacom.github.io/photoshop/

Для публикации: Settings → Pages → Build and deployment → Source → **GitHub Actions**. Затем Actions → **Publish PIXELFORGE to GitHub Pages** → Run workflow, если не запустился автоматически.

## Что работает

- Загрузка фото из галереи, вставка из буфера, drag & drop.
- 14 стилей: Original, Minecraft, GTA Artwork, Anime, Cyberpunk, Cinematic, Noir, Golden Hour, Vintage, Dreamcore, Pixel Pop, Comic Book, Night City, Pencil Art.
- 12 параметров цвета, освещения, резкости и текстуры.
- Кадрирование 1:1, 4:5, 9:16, 16:9, 3:2, перетаскивание кадра, поворот и отражение.
- Рисование, ластик для нарисованных линий, надписи и их перетаскивание.
- Отмена и повторение, сравнение до/после, сброс.
- Экспорт PNG, JPG, WEBP до 4096 пикселей по большей стороне (без увеличения оригинала).
- Обработка фото полностью локальная. Установка на главный экран телефона через браузер. Offline-кэш после первого посещения.

## Важно понимать

Игровые пресеты — это алгоритмические фильтры Canvas 2D: пикселизация, цветовая квантовка и контурная обработка. Они НЕ являются генеративными нейросетями и не способны полностью перерисовать сцену в новый трёхмерный мир GTA/Minecraft. Удаление фона и генеративная замена объектов потребуют подключения AI-модели. Ни одно фото на сервер не отправляется.

## UI/UX и проект

Интерфейс разработан на основе мобильных принципов [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): адаптивность, крупные зоны касания, ясная иерархия и доступность.

- index.html — интерфейс и стили.
- app.js — редактор Canvas.
- icon.svg и manifest.webmanifest — иконка и установка на экран.
- sw.js — офлайн-кэш.
- .github/workflows/pages.yml — публикация через GitHub Actions.

Без npm и внешних JavaScript-библиотек, чтобы не зависеть от CDN. Проект можно расширять WebGL, AI-моделями и слоями.
